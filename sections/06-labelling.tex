\section[Labelling]{Anatomical Labeling of Airway Trees}
\label{sec:labeling}                     % \secref{sec:labeling}

To assign anatomical labels to our airway trees, we used the Implicit Point-Graph Network
(IPGN) of \citet{xie2025}. We did not train this model ourselves: we used the weights
released by the authors, trained on their Pulmonary Tree Labeling (PTL) dataset, and ran the
model in inference mode only. This section summarizes the label definition, the model and its
reported performance and then describes how we applied it to our data.

\subsection{Task formulation}            % 19-class labeling of a binary tree
\label{sec:labeling_task}                % \secref{sec:labeling_task}

The input to the model is a binary volume containing a pulmonary tree (airway, artery or
vein). The goal is a 19-class semantic segmentation of every foreground voxel: 18 classes
correspond to segmental-level branches, i.e.\ the branches that supply the 18 pulmonary
segments, and one class corresponds to the extra-pulmonary structures \cite{xie2025}. Labels
1 to 10 are branches in the left lung, labels 11 to 18 are branches in the right lung, and
label 19 is the extra-pulmonary part \cite{xie2025}. The correspondence between label indices
and segmental bronchi is given in Table~\ref{tab:ipgn_labels}.

Since branching points and distal end points contain very few voxels, a high voxel-level
score does not guarantee correct labels at these key locations; IPGN therefore also
represents each tree as a skeleton graph whose nodes approximate the key points
\cite{xie2025}.

\subsection{Model}                       % overview-level description only
\label{sec:labeling_architecture}        % \secref{sec:labeling_architecture}

\paragraph{Input representations.}       % point cloud + skeleton graph
Instead of processing the dense volume with a CNN, IPGN works on two sparse representations
of the tree \cite{xie2025}. The first is a point cloud of $M = 6{,}000$ randomly sampled
foreground voxels. The second is a skeleton graph built with the VesselVio software
\cite{bumgarner2022}, which applies the thinning algorithm of \citet{lee1994} to extract the
centerlines: centerline segments become edges, and centerline intersections and distal end
points become nodes. The only input features are the $(x, y, z)$ coordinates of the points
and nodes.

\paragraph{Architecture.}                % encoders, fusion, implicit module
The model has three stages (Figure~\ref{fig:ipgn_overview}) \cite{xie2025}. First, a point
encoder and an 11-layer graph attention network (GAT) \cite{velickovic2018} compute an
initial feature for each point and each graph node. The point encoder is either
PointNet++ \cite{qi2017} or Point Transformer \cite{zhao2021}; the released model we used has
a PointNet++ encoder. Second, a stack of Point-Graph Fusion layers
exchanges information between the two branches: each graph node aggregates the features of
the points within a small ball around it, and each point aggregates the features of its
nearest graph nodes, weighted by inverse distance. In this way, the points receive the
structural context of the skeleton and the nodes receive local shape information. Third,
the Implicit Point Module labels every foreground voxel, not only the 6,000 sampled points:
for any query location, it interpolates the features of the nearest sampled points from all
fusion stages and maps them to 19 class scores with a small MLP. The network without this
module is called the Point-Graph Network (PGN).

\subsection{Training data and reported performance}  % PTL + Dice scores, condensed
\label{sec:labeling_data}                % \secref{sec:labeling_data}

The released weights were trained on the PTL dataset \cite{xie2025}, which contains 800
subjects from multiple medical centers, each with an airway, artery and vein volume
annotated with the 19 classes by a junior radiologist and verified by a senior radiologist.
The CT volumes have $512 \times 512$ slices, between 181 and 798 slices per scan, and a slice
spacing between 0.5 and 1.5~mm. The point and graph encoders were first pre-trained
separately and frozen; the fusion layers and the Implicit Point Module were then trained
jointly with a cross-entropy loss, using random rotation, shifting and scaling as data
augmentation \cite{xie2025}.

Performance is measured with micro-averaged Dice scores at two levels \cite{xie2025}: at the
\emph{voxel level}, on the labeled volume, reflecting overall performance; and at the
\emph{graph level}, on the labels of the skeleton nodes and edges, reflecting performance at
the key locations of the tree. On the PTL test set, IPGN with the PointNet++ encoder reaches a voxel-level
Dice of 87.5\,\% on airways, and 95.1\,\% and 92.3\,\% on graph nodes
and edges, respectively, outperforming CNN-, point- and graph-based
baselines \cite{xie2025}. On a version of PTL with artificially
disconnected trees, its voxel-level Dice dropped by only 1.2 points on average
\cite{xie2025}, which is relevant if the input segmentations are imperfect.


\subsection{Application to our airway trees}
\label{sec:labeling_ours}
\label{sec:labeling_inference}

\paragraph{Pre-processing.}
We applied the released IPGN model with the PointNet++ encoder to our
419 airway trees obtained from the ground-truth airway segmentations of
the ATM'22 and AIIB23 datasets. Each tree was represented as a binary
three-dimensional volume. No additional resampling was performed for
IPGN inference; the coordinates of the foreground voxels, sampled points
and skeleton-graph nodes were normalized to the unit cube using min--max
normalization, as implemented in the released code. The anatomical
orientation of the volumes was preserved throughout the preprocessing
pipeline so that the left- and right-lung class assignments remained
consistent.

\paragraph{Inference.}
Following \citet{xie2025}, each binary airway volume was skeletonized
with VesselVio, and 6,000 foreground voxels were randomly sampled to
form the point cloud. A single forward pass of the Point-Graph Network
(PGN) on the point cloud and skeleton graph produced the multi-stage
point and graph features. The Implicit Point Module then used these
features to classify the remaining foreground voxels as query points,
yielding an anatomical label for every foreground voxel of the airway
tree. This procedure avoids repeatedly running the complete network for
each subset of foreground voxels and provides an efficient dense
reconstruction \cite{xie2025}.

\paragraph{Quality control.}
Because our airway trees do not have ground-truth segmental annotations,
the quantitative Dice scores reported on the PTL dataset cannot be
directly evaluated on our data. The predicted anatomical labels were
therefore treated as model-derived annotations and inspected qualitatively
for anatomical plausibility and consistency between the left- and
right-lung branches. No quantitative accuracy measure was assigned to
these predictions.

\paragraph{Limitations.}
The performance figures above were obtained on the PTL dataset, whereas
our data differ from PTL in acquisition characteristics, pathology and
the upstream airway-segmentation procedure. The predicted labels should
therefore be regarded as model-derived anatomical estimates rather than
ground-truth segmental annotations. The resulting labels are used in
\secref{sec:morphometrics} to compute the morphological descriptors of
each anatomical class.
